# KWC CONNECT – DESIGN SYSTEM

## Design Philosophy

The application should feel like a modern government digital service.

Focus on:

- Simplicity
- Accessibility
- Trust
- Professionalism
- Clean layouts

Avoid:

- Fancy gradients
- Heavy animations
- Social media style UI
- Decorative elements without purpose

# Color Usage

White backgrounds should dominate.

Maroon is used for:

- Primary buttons
- Active navigation
- Important actions

Navy is used for:

- Titles
- Headers
- Icons

Gold is only used for emphasis.
