# MILESTONE 1 – PROJECT FOUNDATION

## Objective

Prepare the KWC Connect project foundation for long-term production development.

This milestone focuses only on establishing the architecture, theme system, and project structure.

No business features should be implemented during this milestone.

---

## Scope

This milestone includes:

- Review the existing Expo project.
- Review the existing folder structure.
- Analyze the current Expo Router setup.
- Ensure React Native Web compatibility.
- Prepare the project architecture for future development.
- Create the centralized Theme Architecture.
- Create Design Tokens.
- Prepare reusable project configuration.
- Prepare Firebase configuration placeholders.
- Prepare API service placeholders.
- Prepare localization structure.
- Prepare shared utility structure.
- Prepare reusable component architecture.

---

## Theme Architecture

Prepare the following theme structure.

theme/

- colors
- typography
- spacing
- radius
- shadows
- elevations
- light theme
- dark theme

No UI screens should use hardcoded colors.

---

## Design Tokens

Prepare centralized design tokens for:

- Colors
- Typography
- Font Sizes
- Font Weights
- Border Radius
- Shadows
- Elevation
- Spacing

Everything should be reusable.

---

## Folder Structure

Respect the existing Expo project.

Do not reorganize existing folders.

Only create folders that are required for future development.

---

## Services

Prepare placeholders only.

Do NOT implement Firebase.

Do NOT implement APIs.

Do NOT implement Supabase.

Only prepare the folder structure.

---

## Localization

Prepare localization architecture.

Do not add translations yet.

---

## Components

Prepare the shared component architecture.

Do not build actual components.

Only organize the project.

---

## Constraints

Do NOT create:

- Authentication
- Login
- OTP
- Registration
- Dashboard
- Complaint Screens
- Hearing Screens
- Counselling Screens
- Notifications
- Firestore Collections
- API Endpoints
- Business Logic

Do NOT install new packages.

Do NOT modify package.json.

Do NOT modify existing Expo configuration unless required.

---

## Deliverables

At the end of this milestone the project should have:

- Stable folder structure
- Theme architecture
- Design tokens
- Shared project organization
- Ready for Authentication milestone

Nothing else.
